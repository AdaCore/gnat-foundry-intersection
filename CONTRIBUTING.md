# Contributing

## Contributor License Agreement

Contributions are accepted under AdaCore's Contributor License Agreement. You
will be asked to sign it on your first merge request; the check must pass
before a change can be merged.

## Ground rules

All changes go through merge requests; CI must be green; requirement IDs are
stable forever (never reused, even if deleted).

## Development

See [`DEVELOPERS.md`](DEVELOPERS.md) for toolchain setup and the build, test,
and proof workflow.
